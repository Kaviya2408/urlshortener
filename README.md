URL Shortener 🔗

A simple and efficient URL Shortener web application that converts long URLs into short, easy-to-share links. This project is built to demonstrate full-stack development concepts including frontend design, backend API handling, and database storage.

Features ✨

Convert long URLs into short links

Fast redirection to original URLs

Clean and responsive user interface

Unique short code generation

Error handling for invalid URLs

Lightweight and easy to deploy

How It Works ⚙️

User enters a long URL in the input box.

The system generates a unique short code.

The short link is stored in the database.

When the short link is accessed, the user is redirected to the original URL.

Installation & Setup 🚀
1. Clone the Repository
git clone https://github.com/your-username/url-shortener.git

2. Navigate to Project Folder
cd url-shortener

3. Install Dependencies
npm install

4. Start the Server
npm start


Server will run on:

http://localhost:3000
